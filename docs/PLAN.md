# Plan

1. Calendar: live, scheduled and ended promotions on month, week and timeline views, with overlap and stacking flags.
2. Copilot: chat that lists, creates and edits promotions via draft, diff, confirm, apply. New promotions start disabled.
3. Audiences: customer groups (and segments where the store has them) with the promotions that touch them.
4. Recommendations: calendar gaps, seasonal events and order history, each with a one-click "draft this".
5. Preview: storefront banners and cart messaging for a promotion, by audience.
